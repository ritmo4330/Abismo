# AVG 场景美术与流程改造

## 制作方向

《异数》采用剧本杀式文字冒险：固定背景点击调查、证物查看与深入调查、人物交谈与私聊、疑点和证据推理、信任与记忆条件分支。普通探索不再要求操纵地图角色行走。剧情演出仍可使用自动横移、渐黑与章节标题。

以《异数改编项目策划案》四、游戏流程及已有修订文档为核对依据。本轮没有改写、删除或新增人物台词，77 个现有对话文件的 SHA256 与改造前一致。

## 美术风格与复用提示词

参考原有 NPC 手绘立绘、雪地横幅、室内物件和剧情 CG，提取以下特征：不完全规整的炭黑描边、克制的日系人物插画感、低饱和灰蓝与灰褐、骨白高光、哑光平涂阴影、细微纸张颗粒。灯光只用少量暗琥珀色，保持雪夜悬疑气氛。没有替换用户提供的人物立绘、Logo 或尸体 CG。

可复用中文提示词：

> 为《异数》制作 16:9 固定视角 AVG 场景背景，平视构图，手绘炭黑细描边，克制的赛璐璐阴影与哑光水粉质感，低饱和灰蓝、灰褐、骨白与炭黑，少量暗琥珀灯光，寒冷雪夜与安静不安的悬疑气氛。调查物件清楚分离，与现有立绘配色统一。画面下方约 22% 保持简洁，留给独立绘制的对话界面。不绘制人物、尸体、可读文字、标牌、界面或水印，不使用写实摄影、3D 渲染或像素画。

具体物件、位置和各场景英文提示词记录在 `assets/art/static_scenes/generation_prompts.json`。书房首张仅保留了可复用制作说明，其余生成及编辑提示词按实际调用记录。使用内置图像生成工具生成，不依赖外部 API 密钥。

## 素材范围

19 张 PNG 保存在 `assets/art/static_scenes/`，原生成结果也保留在生成目录，没有覆盖旧素材。

- 书房、大厅、一楼走廊、二楼走廊、餐厅、会客厅。
- 林玖、穆执、乌停湘、钟歧、周崇安、梅塔六间客房。
- 厨房、食品储藏室、储物间。
- 地下走廊、钟岳研究所；研究所同时用作章节间 CG。
- 穆执房间早期干净版本，以及发现尸体消失后的林玖房间版本。

这是当前已实现调查地点的场景美术批次，不代表策划案全部梦魇、记忆及结局专用 CG 均已绘制。

## 接入与操作

`manifest.json` 使用 1920×1080 归一化坐标配置画面与物件。新背景接入后，旧俯视地图仅停止显示，原有线索 ID、线索文字、深入调查树及剧情判定继续复用。

画面物件可直接点击。重叠区域优先响应尚未收录的线索，同等条件下优先更小的调查物件；已收录物件仍能重复查看与深入调查，不因取消光点而丢失入口。人物入口使用原立绘裁成的头像卡片，点击后进入原对话。

地点切换在画面底部；厨房、食品储藏室、储物间是大厅所属独立视图，显示各自证物。储物间的画面门也能直接点击进入，不再错误地重新加载大厅。当前视图纳入本地存档，旧档没有该字段时仍回到默认视图。初次人物介绍阶段仍由管家限制离开，不开放提前搜证。

底部界面复用原对话框、姓名框纹理及 Nightgazer 字体。修复了菜单锚点在屏幕外的问题；地点按钮可换行。对话期间隐藏探索界面，继续使用原有左右轮替立绘、历史沙漏、Ctrl 加速与选项暂停功能。

## 流程优化

- 保留初识全部话题、第一轮搜证及管家抉择 14，不把收齐线索直接改成自动跳过推理。
- 普通场景不依赖玩家走到触发区；已有自动叙事链继续生效。
- 剧情请求若撞上正在执行的转场，进入待执行队列，不再直接丢弃；重新开始时清空队列。
- 菜单与物件映射不再为取得目的地名称而实例化所有相邻房间，减少不必要的旧地图贴图加载。
- 原有第三轮搜证顺序、私聊选项条件、信任、梦魇、记忆碎片及结局判定没有删除或改成无条件放行。
- 导出预设包含场景映射清单，避免本地能运行而朋友设备缺少映射。

## 校验与边界

可运行的回归脚本位于 `scripts/tests/`：`validate_static_art.gd` 检查场景背景、证物入口、服务区域隔离、视图恢复、真实点击事件、人物入口与窗口布局；`validate_static_progression.gd` 覆盖序章、书房、地下走廊三个自动流程；`validate_dialogue_archive_ui.gd` 检查历史沙漏与推理手册；`validate_avg_choices.gd` 覆盖初识话题、第三轮搜证顺序分支及乌停湘第三轮私聊。

策划案一致性检查现在可直接读取 DOCX：

```text
python -X utf8 scripts/tests/validate_planning_text.py --source <策划案.docx> --source <需修改内容.docx> --limit 30
```

自动文字比对不能读取策划案中图片形式的对话流程图，也不能判定一句改写是否等义。因此未匹配的条目不是已确认错误数量，必须结合原图人工核对。现有第三章集中叙述、部分记忆复现和管家帮助中的占位文本仍需与完整策划案逐项核对；本轮遵守“人物对话不变”，没有擅自补写替换。

新素材接入和节点回归通过，不等于全部梦魇、三条记忆条件及四结局已完成逐分支人工通关验收。旧场景还有贴图 UID 回退告警，当前可按实际路径加载；引擎退出时已有 Dialogic 资源释放告警也仍存在。

本轮已通过：15 个场景实例的背景接入、服务区域与视图恢复、鼠标点击收录新线索、屏幕菜单布局；五位角色的 15 个初识话题；第三轮搜证第 3 与第 6 顺位的已知尸体差异分支；乌停湘第三轮私聊四个话题及结束条件；序章七段自动叙事、书房调查后自动推理、走廊—实验室 CG—章节转场；历史沙漏和推理手册回归。尚未遍历所有结局与所有信任阈值的组合。

## 剧情与调查界面区分、小说辅助

探索界面现在以明确流程节点判断开放，不再仅检查是否有对话：序章、自动演出和转场不显示探索菜单或调查标记，也不能打开调查系统；自由调查时恢复。交互式推理只显示推理手册入口，不提供地点与人物导航。

书房在醒来、自由调查及未结束的小说谜题阶段由流程规则统一锁定，点击画面门或旧交互入口均不能跳走。小说谜题中同一疑点作出三次无效推理后，面板持续显示所需线索名称；若线索尚未取得，会说明先解决其他小说疑点。提示不填入线索、不自动解决疑点，错误次数随游戏 flags 存档，新游戏重置。

调查标记曾试用 `assets/UI/investigation_mark.svg`，现按玩家反馈恢复原金色渐变发光与呼吸节奏，仍保留剧情期间隐藏的规则。底部菜单按内容宽度居中，人物卡和地点按钮支持换行，减少无用留白。

对应回归入口：`scripts/tests/validate_presentation_polish.gd`，支持 `--capture` 保存实际渲染截图。

## 书房进入时的调查锁死修复

旧场景的延迟呈现回调可能在新场景转场期间执行，提前清空待播时间线。对话管理器此时拒绝播放，流程便滞留在书房醒来节点，调查点击也被剧情状态拦截。待播时间线现在在转场或其他对话期间保留，等待新场景呈现或对话结束后播放。章节标题跳过输入也不再引用不存在的 interact 动作。

新增 `scripts/tests/validate_study_click.gd`：覆盖旧场景回调竞争，以及 `--chapter-title` 的正常第一章标题入口；实际鼠标事件逐一点击书房五个线索，均能收录。书房自动进入小说谜题和剧情界面/小说提示回归均通过。
