# 餐厅后门与花海修复

## 原因

- 餐厅原先只有通往大厅、走廊的门；右侧带符号的门只是 `1_dining_2` 线索热点，没有开门操作或场景目标。
- `flower_sea` 的尸体、白色连衣裙及三个尸体细节已有原文资源，但缺少可进入场景、背景配置和线索投放，因此普通游玩无法到达。
- 新场景初次接通测试时，手册首页覆盖调查画面，影响首次连衣裙点击；现已让花海直接进入调查画面。

## 修复内容

- 新增餐厅后门实体与四手印面板，保留原有“奇怪的门”原文与线索记录。画面热点、线索点击和导航按钮使用同一个门锁逻辑。
- 潜意识调查开启后，识别钟岳、梅塔、周崇安、异测会四处研究所的既有公开记录。兼容旧存档中已收集的对应证据，不自动补发任何未获得的线索。
- 选择 α、β、γ、θ 后，必须点击“确认同时按下”才能开门；选择、取消或只选三个均不解锁。源资料未给出完整的符号与人物一一对应关系，未自行编造此类答案或新增剧情对白。
- 新增独立 `flower_sea.tscn`。尸体、白色连衣裙热点与图上位置一致，尸体保留原有三个深入调查项目。
- 花海可从画面门返回餐厅；开门状态持久化。地图增加“后院 · 花海”，未开门时不可绕过机关进入。
- 从其他房间进行花海场景复现时，先切换到已开启的花海，再播放已有原文。

## 临时美术说明

内置图像生成连续两次返回网络错误，没有生成可用图片；没有改用 API 或读取密钥。用户随后明确选择“先用游戏内绘制的临时花海”。

临时背景为游戏原生绘制：`scripts/scenes/flower_sea_background.gd`，包括别墅后立面、花海、左侧防盗杆尸体、右侧折叠连衣裙与返回门。它不是最终手绘美术，也不是已成功生成的 PNG。

以后提供 `assets/art/static_scenes/flower_sea-v1.png` 并导入即可优先使用正式背景，原生绘制自动退居后备；无需改变线索、门锁或存档格式。

## 验证

- 新增专项实际鼠标事件测试：早期锁定、调查前置、四手印确认与取消、旧记录兼容、进入花海、衣裙与尸体收录、尸体深入调查、返回、再次进入、地图出入、独立测试槽保存和读取。
- 完整专项在无界面模式、兼容渲染模式下均验证；兼容模式保留实际运行截图，检查了门锁面板与花海画面。
- 后期路线菜单回归、手册证据确认回归另行运行；原有退出时资源清理警告仍存在，不把该警告表述为已修复。
- 测试使用独立存档槽，结束后删除测试槽并还原原来的最近存档指向，不覆盖玩家存档。

范围：修复餐厅后门及花海路径，不宣称全游戏已完成。第三轮调查前后仍需按策划收集相应研究所资料；不是到达餐厅就无条件打开后门。
