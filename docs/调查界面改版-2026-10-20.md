# 调查界面改版

参考玩家提供的四张图片，采用纸页调查菜单、双页地图和手册的交互结构；不使用参考游戏的角色、文字、标志或截图裁片。

## 操作

- 自由调查时，右侧菜单提供推理、对话、探索。对话对象以纵向头像卡显示，左侧预览已有立绘；点击后进入原有剧情对话。
- 探索收起右侧纸页，直接点击场景高亮收录线索。下方可返回调查菜单、打开地图、线索与推理。
- 地图左页为别墅楼层示意，右页列出当前可达地点。使用原房门、楼梯和区域切换入口，不跨过原有通行条件；灰色地点当前不可进入。未初识角色的房间先显示客房。
- 任务入口打开只读双页任务簿。目标与进度来自当前流程、收录线索及话题完成状态；推理阶段只显示完成推理，不透露答案。系统界面使用同一份任务数据。
- 调查手册保留线索/推理页切换、搜索、分类、阅读、深度线索、证据选择与原有验证。推理证据卡自动换行，保留锁定疑点与小说失败提示。
- 自由阶段可使用菜单中的存档、读档、历史和系统；剧情、序章、CG 和章节转场时不出现调查菜单。

## 风格与实现

复用现有背景、立绘，不修改原来的对话布局。内置 ImageGen 多次网络失败；用户随后同意备用方式，但本机没有 API 密钥，因此未产生付费 API 调用。此次实际应用的是 CC0 旧纸实物扫描与引擎内合成：纸边、错位叠页、双页书脊、别针纸签、复古测绘与放大镜装饰。新增 SIL OFL 授权的 Noto Serif SC，标题使用可变字重而非粗描边。材质用 mipmap 与线性过滤，避免缩放噪点。所有来源与许可保存在 assets/art/casebook/CREDITS.md，生成提示词仅作未执行方案保留，不将合成素材宣称为成功生成的 AI 图。

地图新增常驻入口与 M 键开关。房间可达性从实际场景出口建立，支持跨楼层选择非相邻的可达房间；剧情信号门不参与快捷路径，出发前重新验证通行条件。进入目标房间后直接进入静态调查。书房谜题、初次大厅询问等限制仍保留。

关键入口：casebook_hub.gd、villa_floor_plan.gd、casebook_style.gd、casebook_paper.gd、investigation_tasks.gd。所有位置按 1920×1080 设计画布等比适配；手册独立缩放。

## 验证

validate_casebook_ui.gd 检查菜单、六个人物入口、地图暂停与关闭、M 键开关、受限地点、非相邻卧室实际跳转、不可绕过研究所入口剧情、当前位置标记、只读任务页、推理卡片换行和 1280×720 适配；支持 --capture 输出 casebook-v2-* 实际渲染截图。本轮该测试和 validate_dialogue_archive_ui.gd 均通过。

地图打开期间冻结后台导航刷新，避免纸签列表被覆盖；原生平面图提供可点击的房间、当前地点、门窗、楼梯和家具图示。新增回归断言保证打开的地图保留完整可达地点列表；鼠标事件实际点击地图上的非相邻房间后能够切场，测试通过。手册与地图均检查 1280×720 适配。

## 第三版视觉细调

- 主菜单标题从 144/126 调为 116/106；页眉、分类、正文和功能栏分级，调整页内留白，纸面顶线不再穿过标题。地图地名增至 24；手册主标题使用 750 字重、详情标题使用 650 字重，减少不同层级挤在一起的感觉。
- 调查人物预览使用同一 920×1000 区域，按原图透明边界等比显示；软色调、独立投影与淡入，不拉伸原画。预览名签遵循首次介绍解锁，不提前显示姓名。没有改变剧情对话已有的左右站位、替换和明暗规则。
- 六张人物纸签调整为 646×92，76 像素圆形头像，全部可完整显示。头像遮罩按控件坐标工作，支持原画图集，不改写原图。
- 增加原创原生装饰：雪花封蜡、纸夹、植物刻线、双页书签与箭头式位置纸签。装饰只绘制，不增加遮挡鼠标的控件；没有新增剧情文字。
- 探索操作栏移到屏幕下方居中。收录通知移到顶部安全区，并按窗口宽度调整字号和宽度，缩放窗口时同步更新。
- validate_casebook_ui.gd 新增逐角色预览比例、名签保密、纸签完整显示、通知小窗口宽度检查；--capture 输出 casebook-v3-*，--portraits 可额外输出各角色预览图。

## 左线索、右问题的推理工作区

推理页左侧改为已收录线索目录、搜索、正文预览及加入证据；右侧为已发现问题选择、问题正文、已选证据及确认推理。选择右侧证据位后可在左侧替换，支持移除、双击加入、自动移到空证据位。选证不再弹出另一整页遮住问题。

旧疑点树保留为内部数据选择适配，不再作为左页展示。搜索只查已收录线索，不列出尚未获得或未解锁的证据；问题下拉只列已发现问题。强制推理仍锁定当前问题、关闭按钮及手册切页，但允许浏览和搜索证据。没有改变所需线索、重复证据处理、小说失败提示阈值、结论与后续剧情事件。

新增 reasoning_workspace.gd 组织界面，suspicion_ui.gd 继续执行原判定与结论流程。validate_reasoning_workspace.gd 用鼠标点击检查同屏加入、移除、重复证据、问题切换后保留选证、锁定限制、小窗口适配以及原题推理成功；结合历史手册和小说三次失败提示回归测试验证。

普通线索交互和线索档案也使用左线索原文、右已收录问题的布局，由 clue_question_workspace.gd 组织。可以选定问题进入同屏推理，保留当前阅读的线索作为左侧预览，但不会自动填答案或推断两者相关性。没有发现的问题不会出现在右侧；有强制后续剧情的收录弹窗禁用进入推理，关闭后继续原剧情。场景交互隐藏不可用的搜索/排序行；普通档案仍保留搜索和排序。

旧 clue_selection_requested 选证入口会路由到新的同屏工作区，并保留锁定问题和证据位置的限制。新增回归检查场景线索到推理的暂停接续、阅读线索保留、无自动答案、无问题时禁用、强制后续剧情不可绕过、旧入口兼容；书房五处实际点击收录、手册搜索与原始推理判定回归通过。

另回归历史沙漏、锁定推理、选证验证、书房开场后的五处线索、小说提示、剧情界面隐藏及静态场景。没有修改策划案对白、信任阈值、记忆碎片条件或结局判定。该验证不等于重新遍历全部剧情组合；已有旧贴图 UID 回退和引擎退出资源告警仍需单独处理。
# 纸页字体统一（2026-10-20）

- 调查报纸、人物话题纸条、地图、线索与推理页统一采用朱雀仿宋；以暖褐墨色取代生硬的黑字，去掉地图文字的浅色投影。
- 正文使用常规字重，标题仅轻微加重；富文本正文及强调段落显式绑定同一字形，避免回退到旧像素字体。提示纸条也使用同一正文字体。
- 字体随游戏素材提供，不依赖测试设备安装。附带 OFL 授权；保留思源宋体作为缺字后备。原人物对白、章节逻辑、左线索右问题的交互和存读档不变。
- 验证：`validate_casebook_typography.gd` 检查对白、线索和界面汉字覆盖；`validate_casebook_ui.gd` 与 `validate_reasoning_workspace.gd` 检查实际点击、地图限制与 1920/1280 窗口布局。
