# 手写笔记界面

按用户确认的第一版样图，将手册及关联纸页界面统一为手写调查笔记风格。没有采用后来的拼贴提案。

- 随游戏提供霞鹜文楷 GB 字体，按参考图的钢笔楷写字形调整字号与间距，取消人工加粗，附 OFL 1.1 授权；霞鹜文楷与原缺字后备字体用于补齐少数字形。生成样图没有对应字体文件，实机采用可嵌入的字形实现。
- 线索、疑点、人物以三枚纸质页签切换。左页保留搜索和目录，右页独立阅读，长文本可滚动。
- 增加圆角纸页、书脊、低对比横线、纸张纹理、红笔圈选与浅色笔迹；红色划线具有轻微起伏和粗细变化，目录的人名采用较大字号。
- 全屏填空推理沿用纸页、手写字及红笔强调；保留原来的确认、锁定、撤回、强制推理和回看规则。
- 线索、疑点、当前问题的标题旁各提供展开箭头。展开后只显示该栏并占用整个内容区，再点收回恢复三栏；不重建内容、不清空填空或选择。
- 修复导出配置：明确包含 `assets/data/evidence_cards/*.json`，避免新增卡片在工程内正常、在导出包中缺失。
- 没有改写对白、线索和疑点的原文、剧情条件或存档格式。

验证：线索卡片、全屏推理、字体字形覆盖、历史手册、搜身汇总、调查界面专项通过；检查 1920×1080 与 1280×720 实际画面。推理测试继续检查填入不锁定、完整提交后只确认正确线索、错误线索可替换以及已确认线索恢复。

以上为本次界面及相关流程验证，不代表遍历全部路线通关。测试进程退出时仍有工程已有的资源释放警告。
